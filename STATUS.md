## Summary
**Latest headline (2026-06-18 pm):** Implemented and measured the P0–P2 changes from the morning's review. **Structure is now deterministic** — the Structure stage emits a structured-JSON section and Python renders guaranteed-clean LaTeX (real comparison tables, balanced boxes, no leaked labels, empty columns pruned), so **structure is no longer a syntax-level failure**. Added an **independent NLI fact-check** (`nli_filter`, a cross-encoder entailment model distinct from the writer) that drops source-*contradicted* points; **de-hardcoded** the scope gate (rejection set derived from the deck's own topics); rewrote `lecture-summariser-proposal.tex` around the honest slides-only product (Phase-2 optional, Phase-4 + web-agent cut) and rebuilt the PDF; and built a reproducible eval harness (runner + objective structure metrics + multi-judge panel). **Blind 3-judge A/B on held-out L3:** OLD 14.6 → NEW (deterministic+NLI) **15.6** → NEW+**qwen3-8b 16.0**/30 — Correctness **3.0→4.3→5.0**, Structure **4.3→5.0**, with the whole LaTeX-defect class gone (objective: L3 tables 3→6, 0 defects). Held-out **L5 generalises** (15.0, Structure 5.3). Cost: Coverage **−1.0** (NLI + pruning trade breadth for fidelity).

> **Honest caveat:** Correctness moved but the ceiling persists. The NLI gate catches the *contradiction* class (swapped stemming/lemmatisation defs, inverted IDF, garbled vectors — all gone in NEW) but by design **keeps neutral content**, so **fabrication-by-omission survives** (an invented "Document Search" section from near-empty slides) plus cross-topic textbook bleed (n-gram LM material). Coverage regressed ~1 point. Renderer fixes made *after* the measured run (prune all-empty columns, toprule/bottomrule) push structure higher than the scores above. The eval is stronger (3-judge panel + objective metrics) but still NLP-course decks only — no non-NLP deck exists in `inputs/` to test true generalisation.
